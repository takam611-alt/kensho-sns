# ゆでたまSNS

招待制の小規模SNSです。

## 現在の機能
- 表示名 + 4桁PINで登録 / ログイン
- 端末では自動ログイン
- 招待コード制
- タイムライン
- 通常投稿 / 懸賞 / 当選報告 / アンケート種別
- 写真投稿
- いいね
- コメント
- メンバー一覧
- プロフィール
- アイコン画像
- ログアウト

## 公開方法
このフォルダの `index.html`、`styles.css`、`app.js` を GitHub Pages のリポジトリ直下に置けば動かせる構成です。

Supabase のプロジェクトURLと Publishable Key は `app.js` に設定済みです。
Publishable Key はブラウザ公開用のキーで、サーバーの Secret Key は含めていません。
